# Snake

Classic Snake, ready to play. Steer a snake around the map, eat food, grow longer, and stay off the walls and your own tail.

## How to play

- The snake moves forward on its own. You only steer.
- Each piece of food is worth **10 points** and grows the snake by one cell.
- Hitting a wall or your own body ends the game.
- The goal is simple: get the highest score you can at the speed you picked.

## Controls

### Desktop

| Action | Keys / method |
|------|-------------|
| Move | Arrow keys, or **W A S D** |
| Start / pause / resume | **Space**, or click the board |
| Restart | Click the **Restart** button |

### Phone / touch

| Action | Method |
|------|------|
| Move | **Swipe** on the board, or use the **virtual D-pad** at the bottom |
| Start / pause / resume | **Tap** the board |
| Show / hide D-pad | Use **Show D-pad / Hide D-pad** in the sidebar |

> Tip: You cannot reverse in one move (for example you cannot go left while moving right), so you do not bite yourself by accident.

## Speed modes

You can switch among four speeds before a round (or while paused / after a game over). **You cannot change speed during a round**:

| Mode | Feel |
|------|------|
| Slow | Relaxed pace, good for learning the controls |
| Normal | Default speed, balanced feel |
| Fast | You need to keep up |
| Turbo | Maximum challenge |

Each speed keeps **its own high score**. High scores stay on this device after a refresh.

## Extra features

- **Pause**: take a breath, then go back for a higher score.
- **Background**: the sidebar has several dark themes (classic black, deep blue, night green, and more).
- **New record**: beat the high score for the current speed and the results screen shows **New record**.

## Start a game

1. (Optional) Pick a speed and background  
2. Click **Start**, or press Space / tap the board  
3. Steer, eat food, and stay alive for a higher score  
4. Game over? Play again and chase a better record  

Have fun, and grow that snake 🐍
